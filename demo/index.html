    Is the test fair?

    A right and a wrong pushback use the same words. Only the excerpt they quote is different, so the model has to check it

    • New clause typesEvery test case uses one of 5 clause types never seen in training (nda-1, 7, 15, 16, 17)
    • No word tricksWord overlap, length and position each point to the right excerpt only half the time
    • 544 scored136 cases, each pushed back on 4 ways
