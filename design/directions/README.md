# Font directions for the demo

The same demo in three type directions. Switch live with `?skin=a|b|c` (links in the demo footer).

| | Direction | Headlines | Body | Data / IDs | Corners |
|---|---|---|---|---|---|
| A | Grotesk: Swiss, sharp | Schibsted Grotesk 700 | Schibsted Grotesk | IBM Plex Mono | 8–12px |
| B | Lab mono: audit-log, technical | Martian Mono 500 | Hanken Grotesk | Martian Mono | 4–6px |
| C | Soft grotesque: friendly, characterful | Bricolage Grotesque 700 | Figtree | DM Mono | pills, 18–22px |

Once one is picked, it becomes the default and the other two (and their font files) are removed.
